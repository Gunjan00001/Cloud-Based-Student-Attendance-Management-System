Consistency rules

  • Read-your-writes: attendance save returns the canonical session from the primary
  • Lag is honest: replica reads carry a dataAsOf timestamp
  • Never on the replica: authorization, credential checks, edit-form version numbers
  • Lag > 10s: alert; > 60s: circuit-break non-report reads to primary
  • Replica is not a backup and never promoted on primary failure — writes just return 503
  • Pooling: transaction-mode poolers, prepare:false, Drizzle migrations against primary only
