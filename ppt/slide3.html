USERS & PERMISSIONS

Three roles, enforced server-side

A

Admin

  • Manage users, courses, enrollments
  • Create sessions for any course
  • View all reports and any student's record
  • View the audit log

DEACTIVATES ACCOUNTS

T

Teacher

  • See only assigned courses
  • Create and edit sessions for own courses
  • Mark attendance (present/absent roll call)
  • View own-course reports

NO MARKING RIGHTS ELSEWHERE

S

Student

  • See only enrolled courses
  • View own attendance history only
  • No write access anywhere

OWN RECORD ONLY

UI hiding is not authorization. Every query is scoped by the authenticated user's role and relationships in the server service layer.
