SECURITY & HARDENING

Defense in depth, boring on purpose

AUTH & ACCOUNTS

  • Argon2id password hashing; 12–128 chars
  • Auth.js JWT in httpOnly, Secure, SameSite=Lax cookie; 8-hour lifetime
  • No public signup — admins provision accounts
  • New/reset accounts must change password at first login
  • Deactivation takes effect at next login / token refresh

INPUT & INJECTION

  • Zod validation at every API boundary; unknown fields rejected
  • Parameterized queries via Drizzle — no string SQL
  • React escaping; no dangerouslySetInnerHTML; strict CSP

RATE LIMITING (SHARED REDIS)

  • auth.login.email: 5 / 15 min, fail closed
  • attendance.write.user: 30 / min, fail open
  • read.user: 120 / min · global.ip: 600 / min
  • 429 responses include Retry-After + UI countdown

TRANSPORT & DATABASE

  • HSTS, nosniff, Referrer-Policy, frame-ancestors
  • TLS with verify-full; least-privilege DB roles
  • No public schema writes from the browser
  • PII redacted from logs; rate-limit identities hashed
